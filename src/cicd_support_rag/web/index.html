This assistant searches the adapted PipelineHub documentation and prepares answers with sources you can inspect.

When a question needs more detail, it asks. When the evidence isn't sufficient, it prepares a human-review message. It does not submit a support ticket.

Chats are saved in this browser. Answers use the configured model provider; document search uses Pinecone. When Nebius is selected, your question and retrieved documentation excerpts are sent to Nebius. Documentation links and commands are illustrative.
